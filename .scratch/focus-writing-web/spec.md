# 专注写作 Web 前端

用户于 2026-10-13 审核交互设计后，明确选择“专注写作”方向并授权开发。

- 保留暖白与墨绿视觉、横向导航、左侧集/场景目录、中间剧本纸页、右侧可收起的创作助手。
- 使用 React、TypeScript、Vite，提供明确区分的示例体验与真实账号会话。
- 接入作品创建、创作资料、阶段确认、变更提案、结构化工作草稿、片段重写、版本比较/恢复、正式稿发布与双格式导出。
- 作品权限独立于平台角色；管理员不能绕过作品成员权限。
- 外发确认绑定当前输入 revision、模型配置版本和数据类别；未保存内容先保存，任何输入变更使授权失效。
- 自动保存只更新工作草稿；明确保存、成功生成、恢复才形成整部作品版本；导出绑定正式稿。
- 支持手机切换目录、正文与创作对话。键盘操作、未保存保护、错误和并发冲突状态必须可用。
- 支持本地开发和 Docker 同源部署。支持真实 OpenAI 兼容与 Anthropic 模型调用；示例与 Mock 明确标注。

设计参考：本会话审核的“幕间 · 专注写作”交互稿。
