# 04: 直接正文生成与选段重写

**What to build:** 所有者和编辑者在三阶段设定有效确认后直接生成或重写目标，过程不弹外发确认，结果保留整部作品版本且不改变非目标正文。

**Blocked by:** 02：限定上下文的直接创作对话。

**Status:** resolved

**用户故事覆盖：** 29–31、68–74。

依据已确认的模型配置、直接发送与流式创作对话规格及 ADR-0011。采用浏览器主验收、真实 API 与独立测试库，仅在模型 HTTP 边界使用可控替身；数据库迁移及并发由独立 PostgreSQL 测试补充。

- [x] 正文生成、选段重写及重试不再需要外发确认标识，移除这两条流程的发送范围弹窗。
- [x] 保留有效三阶段确认、目标与指令校验，使用明确目标的固定上下文和模型版本。
- [x] 任务排队／执行期间继续锁定作品输入，与对话共享同作品活动调用检查；终态恢复编辑。
- [x] 成功只替换目标并生成整部作品版本，未发送的其他正文由服务端保留；失败、取消和结构无效不写入成功版本。
- [x] 继续使用有限重试，每次尝试与结果提交检查有效成员、作品状态、模型启用及取消状态，且不因正常配置更新误判已固定版本不可用。
- [x] 浏览器覆盖所有者／编辑者直接生成、选段重写和版本结果，公开 API 覆盖拒绝矩阵、取消、重试、输入锁和非目标正文保留。
