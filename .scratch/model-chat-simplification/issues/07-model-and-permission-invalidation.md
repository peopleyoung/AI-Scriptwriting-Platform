# 07: 配置更新与失效权限下的调用收口

**What to build:** 管理员更新模型只影响后续请求，停用模型则停止未完成调用；账号停用、成员撤权或作品删除也会及时结束对话与生成。

**Blocked by:** 04：直接正文生成与选段重写；06：停止、断线恢复与手动重试。

**Status:** resolved

**用户故事覆盖：** 75–78。

依据已确认的模型配置、直接发送与流式创作对话规格及 ADR-0011。采用浏览器主验收、真实 API 与独立测试库，仅在模型 HTTP 边界使用可控替身；数据库迁移及并发由独立 PostgreSQL 测试补充。

- [x] 更新模型地址、密钥或参数时，运行中对话与生成继续使用已固定版本，新请求使用新版本。
- [x] 管理员停用稳定模型身份后，不同版本的未完成对话和生成均停止，新请求与排队任务不能继续外发。
- [x] 停用后的页面显示明确中断状态，保留对话部分内容，不能提交正文成功结果，也不能自动换模型。
- [x] 账号停用、成员权限撤销、作品删除在调用及提交边界生效，释放活动调用；不会因取消竞态重新写成成功。
- [x] 正常配置退役与模型主动停用明确区分，历史回复和任务模型归属不被改写。
- [x] 管理员页面操作和双成员浏览器流程覆盖更新／停用，真实 API 加可控模型替身覆盖不同失效原因及对话／正文任务收口。
