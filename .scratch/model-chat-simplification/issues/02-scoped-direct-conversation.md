# 02: 限定上下文的直接创作对话

**What to build:** 所有者和编辑者选择模型与上下文后直接发送对话，未选正文不发送正文，普通对话期间仍可写作，其他成员能看见作品忙碌状态。

**Blocked by:** 01：兼容迁移与独立模型管理。

**Status:** resolved

**用户故事覆盖：** 27–28、32–49、61–70、85。

依据已确认的模型配置、直接发送与流式创作对话规格及 ADR-0011。采用浏览器主验收、真实 API 与独立测试库，仅在模型 HTTP 边界使用可控替身；数据库迁移及并发由独立 PostgreSQL 测试补充。

- [x] 对话发送移除逐次外发确认及对应弹窗；查看者、非成员与未获作品授权的管理员仍不能调用或读取受限内容。
- [x] 默认上下文为当前消息、近期完整对话、设定、大纲和当前集／场景／片段，无目标时不附带正文；整部正文由明确选项加入。
- [x] 展开范围与实际模型请求一致，近期历史窗口可查看；超限在调用前明确提示，不静默丢弃正文或已确认设定。
- [x] 发送前保存参与本次调用的必要修改，绑定内容快照和模型版本；临时指令不覆盖已确认设定，未确认资料保持草稿含义。
- [x] 对话执行中保存正文不丢回复、不覆写正文，不创建正文生成版本；完成的消息和模型引用持久化。
- [x] 同作品活动调用协调同时覆盖新对话与现有正文任务，原子拒绝额外调用；页面显示忙碌并保留输入，不静默排队。生成仍保持原输入锁。
- [x] 重复点击或同一请求网络重发只产生一次消息和上游调用；失败不会自动重发对话。
- [x] 以真实 API 和替身请求内容验证权限、范围、快照与并发；PostgreSQL 并发用例证明不能绕过页面限制。
- [x] 本任务先交付完整回复路径，持续增量输出由 05 交付；正文生成的逐次确认迁移由 04 交付。
