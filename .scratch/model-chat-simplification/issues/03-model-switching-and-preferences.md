# 03: 跨模型对话与个人选择记忆

**What to build:** 用户切换模型后继续同一段讨论，回复显示真实模型来源；不同成员和作品分别记住模型与上下文选项。

**Blocked by:** 02：限定上下文的直接创作对话。

**Status:** resolved

**用户故事覆盖：** 17–26、42。

依据已确认的模型配置、直接发送与流式创作对话规格及 ADR-0011。采用浏览器主验收、真实 API 与独立测试库，仅在模型 HTTP 边界使用可控替身；数据库迁移及并发由独立 PostgreSQL 测试补充。

- [x] A 切换到 B 后历史不清空，B 的实际请求含范围内 A 的完整历史；每条回复显示实际调用模型及版本归属。
- [x] 选择按用户与作品记住，不同成员和不同作品互不覆盖；退出或换账号不误用另一账号的偏好。
- [x] 包含整部正文的选项能记住，偏好不存储 API key。
- [x] 切换只影响下一次发送，不改变当前回复的模型和快照。
- [x] 无可用模型或原选择停用时明确提示，不擅自更换模型发送；可继续手动写作。
- [x] 两个浏览器成员验证独立选择、刷新记忆、历史来源和跨模型实际请求；历史退役版本的模型名称仍能读取。
