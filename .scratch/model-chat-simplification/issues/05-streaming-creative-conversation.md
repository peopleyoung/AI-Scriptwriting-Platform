**What to build:** 用户发送后立即看到消息与回复占位，并在模型完成前逐步读到回复，完成后刷新仍能读取内容和模型归属。

**Blocked by:** 02：限定上下文的直接创作对话。

**Status:** resolved

**用户故事覆盖：** 50–52、57。

依据已确认的模型配置、直接发送与流式创作对话规格及 ADR-0011。采用浏览器主验收、真实 API 与独立测试库，仅在模型 HTTP 边界使用可控替身；数据库迁移及并发由独立 PostgreSQL 测试补充。

- [x] 用户消息、回复占位和服务端可读取的调用状态在发送开始时建立，不等待完整模型结果。
- [x] 两种模型协议均经过实际后端传输和浏览器消费逐步显示文字，不能只后台聚合后一次返回。
- [x] 内容、状态和模型版本可持久化读取，完成后刷新不重复调用或丢失消息。
