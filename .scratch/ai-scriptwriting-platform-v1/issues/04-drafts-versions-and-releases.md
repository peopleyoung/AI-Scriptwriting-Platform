# 04: 工作草稿、生成版本与正式稿发布

**What to build:** 让有权编辑的成员维护结构化剧本工作草稿，让系统区分自动保存与正式版本；让作品所有者比较、恢复和发布不可变版本，为后续模型生成和导出提供稳定内容边界。

**Type:** task

**Blocked by:** 01: 基础工程与账号会话；02: 作品创建与统一访问控制

**Status:** ready-for-agent

- [ ] 正文按集、场景、片段和剧本块组织，片段是生成和选段重写的最小边界。
- [ ] 编辑者和所有者可以修改工作草稿；查看者不能修改，未授权用户不能读取。
- [ ] 自动保存只更新工作草稿，不产生生成版本或正式稿。
- [ ] 作品所有者显式保存正文时创建覆盖整部作品的不可变生成版本。
- [ ] 生成版本保存来源、作者、父版本、内容摘要和作品 revision；历史版本不能更新或删除。
- [ ] 作品所有者可以比较版本；恢复旧版本通过创建新版本完成，不覆盖历史版本。
- [ ] 所有写操作使用 expected revision；并发写入返回稳定冲突而不丢失已存在内容。
- [ ] 作品所有者可以把任一生成版本发布为不可变正式稿，并保留多个发布记录及当前正式稿标记。
- [ ] 编辑者、查看者和管理员无作品所有者授权时不能恢复、发布或导出。
- [ ] API/UI 测试覆盖草稿与版本边界、版本恢复、并发冲突、发布权限和不可变历史。
