# 08: 回收站、备份恢复与首版运维验收

**What to build:** 让平台具备可验证的删除、恢复、备份、安全和单机运维能力；完成从账号到创作、生成、发布、导出、回收站恢复的首版黑盒验收，并确保恢复不会错误复活任务或授权。

**Type:** task

**Blocked by:** 01: 基础工程与账号会话；02: 作品创建与统一访问控制；03: 剧本模板与阶段化创作资料；04: 工作草稿、生成版本与正式稿发布；05: 模型配置、供应商适配与外发确认；06: 异步生成任务与片段重写；07: 协作工作区与 Markdown/DOCX 导出

**Status:** resolved

- [x] 作品所有者可以把作品放入回收站；回收站作品对成员、列表和生成/导出接口不可见。
- [x] 进入回收站时取消排队任务、请求取消运行任务并使外发确认失效；恢复不自动恢复任务、确认或下载链接。
- [x] 作品所有者可以在 30 天保留期内恢复作品；超过保留期的作品按策略永久删除。
- [x] 回收站、恢复和永久删除操作均产生审计记录，清理任务只处理超过保留期的作品。
- [x] 系统每日备份数据库和作品文件，备份独立加密并保留 30 天；备份目录不作为应用可写目录。
- [x] 管理员/运维人员可以执行受审计的备份恢复；恢复后数据库、作品文件和版本历史保持一致。
- [x] 恢复流程验证运行中任务、外发确认、会话和下载链接不会被错误恢复。
- [x] 安全验收确认提示词、模型原文、正文、密钥不会进入日志、审计记录、错误响应或备份清单。
- [x] 干净 Docker Compose 环境可重复完成健康检查、迁移、备份、恢复和最小权限验证。
- [x] 端到端验收覆盖创建账号、首次改密、创建作品、确认设定、外发确认、分段生成、版本恢复、发布、Markdown/DOCX 导出和回收站恢复。
