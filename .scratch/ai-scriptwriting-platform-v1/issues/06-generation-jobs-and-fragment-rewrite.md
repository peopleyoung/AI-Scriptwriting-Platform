# 06: 异步生成任务与片段重写

**What to build:** 让作品所有者或编辑者在三阶段设定已确认且外发确认有效时，按集、场景或片段创建异步正文生成任务；让任务在可追踪、可取消、可重试的状态机中完成，并把成功结果写成新的整部作品版本。

**Type:** task

**Blocked by:** 02: 作品创建与统一访问控制；03: 剧本模板与阶段化创作资料；04: 工作草稿、生成版本与正式稿发布；05: 模型配置、供应商适配与外发确认

**Status:** ready-for-agent

- [ ] 只有有权编辑的成员可以创建生成任务；查看者和未授权用户被拒绝。
- [ ] 正文生成要求三阶段设定已确认、目标范围符合模板结构、输入 revision 存在且外发确认有效。
- [ ] 任务支持集、场景和片段目标；选段重写不跨越片段边界。
- [ ] 任务实现 `QUEUED`、`RUNNING`、`SUCCEEDED`、`FAILED`、`CANCELED` 状态并可查询进度和结果。
- [ ] 同一作品同一时间最多一个运行中的正文生成任务；同一幂等键重复请求返回已有任务。
- [ ] 全局、用户、作品和供应商容量限制可配置，超出时任务排队而不是绕过限制。
- [ ] 只对瞬时错误和受控限流自动重试；认证、参数和内容政策错误不自动重试。
- [ ] 用户可以取消排队任务；运行中任务请求供应商取消并等待 worker 收口。
- [ ] 成功结果只替换目标范围并带入其他内容，提交时校验 source revision，冲突则失败且不产生孤立正文。
- [ ] 取消、超时、结构校验失败和不可重试错误不产生生成版本或半成品草稿。
- [ ] 状态机、幂等、同作品串行、重试/取消、revision 冲突和供应商适配器契约均有 API/worker 测试。
