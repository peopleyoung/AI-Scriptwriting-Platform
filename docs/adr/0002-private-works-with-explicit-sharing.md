# 作品默认私有并通过授权协作

状态：已确认。作品默认只有所有者可访问；所有者可以邀请查看者或编辑者，管理员的账号管理权限不自动授予作品阅读权。平台角色与作品成员角色分离，管理员也必须成为作品成员才能访问内容。这样把平台运维权限与创作内容访问权分开，降低内部作品被越权查看的风险，同时保留团队协作能力。

## Consequences

- 系统需要记录作品所有者、协作者角色、邀请及撤销状态。
- 删除作品、转移所有权、账号停用和恢复操作必须有明确的审计记录。
- 首版不提供管理员绕过作品授权的应用层应急阅读权限；管理员只有在被邀请为作品成员后才能访问正文。
- 作品进入回收站后对协作者不可见，排队任务取消，外发确认失效；恢复后不会自动恢复原确认。
