# 通过作品内输入预览完成协作外发确认

状态更新：2026-10-14，所有者预览审批流程由 [ADR-0011](0011-direct-model-configuration-and-member-invocation.md) 替代。下文保留为历史决策；新规则已实现。

状态：已确认，2026-10-13 页面设计访谈 Q8。编辑者没有有效外发确认时，先明确提交准备内容形成不可变外发输入快照，再提供作品内的授权预览链接；作品所有者经过登录与作品权限检查，审阅该快照并确认，编辑者随后按原快照发起调用。链接只定位预览，不携带作品原文或授予阅读/外发权限；以明确快照和共享定位完成异地协作，首版不增加独立通知或审批中心。

## Consequences

- 预览快照属于作品资料，读取必须经过作品访问控制；接受邀请前、授权撤销后均不能访问。
- 未发送的输入仅在用户明确准备后持久化，准备快照不调用外部模型、不修改正文或创建生成版本。
- 同一快照的模型、消息/指令、目标和数据类别不可在授权后替换；作品输入变化导致快照失效，重新准备并由所有者重新确认。
- 多个编辑者准备请求不代表可以同时生成，任务启动仍遵守 ADR-0009 的作品输入锁和活动任务限制。
