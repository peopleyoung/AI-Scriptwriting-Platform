# 连续剧本文档编辑保留结构化正文来源

状态：已确认，2026-10-13 页面设计访谈 Q3。创作工作区采用连续剧本文档编辑体验，支持集、场景、片段导航和场景说明、动作、人物、对白等剧本块。持久化、生成版本及导出继续使用 ADR-0006 的结构化正文，编辑器内部文档作为其编辑视图，不另立一套版本来源；这样保留顺畅的写作体验，也使片段内重写和双格式导出共享同一正文边界。具体成熟编辑器库由实施评审确定。

2026-10-24 当前实现说明：连续结构化编辑体验不改变作品角色授权。编辑者可以修改工作草稿和创作资料，但显式保存生成版本当前仅 OWNER 有入口（`app/features.py:391-400`）；EDITOR 显式保存为产品待定项 pending。编辑器视图与结构化正文共用同一版本来源，不另立编辑者版本入口。
