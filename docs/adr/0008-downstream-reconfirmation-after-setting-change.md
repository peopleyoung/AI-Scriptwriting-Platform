# 上游已确认设定变更后重新确认下游

状态：已确认，2026-10-13 页面设计访谈 Q5。创作简报的变更提案获批准后，人物和故事大纲进入待重新确认状态；人物变更获批准后，故事大纲进入待重新确认状态。保留下游内容、工作草稿、正文、历史版本及正式稿发布记录，新的正文生成必须等待三阶段再次按顺序确认；以重新确认的操作成本换取后续生成约束的一致性，不能把旧大纲的确认自动理解为对新人物或创作方向的认可。

## Consequences

- 补充 ADR-0003 的阶段确认规则，不覆盖或删除旧的确认快照与历史版本。
- 下游重新确认允许接受保留下来的内容，也允许修订后再确认；待重新确认内容不作为当前有效的已确认设定。
- R4 通过追加确认事件保存阶段内容、来源与上游事件引用，并将“当前确认状态”与历史记录分开。旧的完整确认链按兼容基线导入并标示历史不完整；可证实的依赖断链进入待重新确认，相关内容留在草稿和历史记录中。
- 上游新确认、下游确认失效、受影响待批提案过时、revision 和审计在同一事务提交。正文生成创建、执行、重试和启动恢复均复核完整有效确认链。
