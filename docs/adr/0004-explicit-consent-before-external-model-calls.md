# 外部模型调用前由作品所有者确认

状态更新：2026-10-14，由 [ADR-0011](0011-direct-model-configuration-and-member-invocation.md) 替代逐次外发确认和独立供应商启用说明要求。下文保留为历史决策；新规则已实现。

状态：已确认。平台在任何作品内容发送给外部模型前展示供应商、模型配置版本和数据发送范围，并要求作品所有者确认允许外发；管理员启用供应商本身不代表任何作品同意外发。确认绑定作品输入快照、具体模型配置版本和数据类别；输入快照、模型配置或数据类别变化后立即失效，作品进入回收站也会使确认失效。创作对话的每轮外部调用同样需要确认，但对话不产生正文版本。这样把平台配置和作品授权分开，避免模型接入设置意外扩大作品数据使用范围。

供应商只有在管理员提供数据保留、删除和故障处理说明后才能启用；说明会展示给作品所有者，平台不替供应商承诺其内部数据删除。
