# 正文生成期间锁定作品输入修改

2026-10-14 补充：[ADR-0011](0011-direct-model-configuration-and-member-invocation.md) 将同作品串行范围扩展到创作对话与正文生成。普通对话期间允许编辑正文，回复绑定发送时的内容快照；正文生成期间仍锁定作品输入。原文关于外发确认失效的历史规则由 ADR-0011 替代，新规则已实现。

状态：已确认，2026-10-13 页面设计访谈 Q6。正文生成任务处于排队或运行状态时，暂时锁定整部作品的正文、创作设定及作品参数修改，终态后恢复编辑；任务创建必须先保存当前修改，并在事务内检查输入版本和同作品活动任务。选择等待而不是继续编辑后丢弃生成结果，是因为生成版本覆盖整部作品且绑定整体输入版本。

## Consequences

- 锁定由服务端统一执行，所有作品成员和直接 API 调用都受约束；前端只呈现状态。
- 草稿自动保存、显式保存版本、版本恢复、阶段保存/确认、提案批准和参数更新属于受限修改。阅读、版本比较、取消生成、成员访问管理及基于历史版本的发布/导出仍按各自权限执行。
- 作品所有者仍可将作品移入回收站；该操作先取消任务并使外发确认失效。撤销发起者权限、转移所有权等变化必须由 worker 在调用与提交边界重新校验，避免任务沿用失效权限。
- 仅准备尚未生效的变更提案不改变输入快照，可按原权限提交；批准须等待任务结束。
- 2026-10-13 访谈 Q7 补充确认：排队/运行期间暂停新的外部创作对话发送，保留未发送输入，历史对话仍可阅读。
- 排队超时、worker 失联和取消需要服务端收口为明确终态，不能依靠浏览器在线维持锁定或释放锁定。

2026-10-24 当前实现说明：本 ADR 中的锁与冲突约束仍有效；涉及角色的部分按当前入口解释：显式保存版本当前仅 OWNER 可调用（`app/features.py:391-400`），EDITOR 显式保存为产品待定项 pending。原文关于“外发确认失效”的历史规则已由 [ADR-0011](0011-direct-model-configuration-and-member-invocation.md) 替代，当前创作对话和正文生成由具备作品编辑权限的成员直接发起。
